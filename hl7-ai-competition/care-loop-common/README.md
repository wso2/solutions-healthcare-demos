# care_loop_common

Shared Ballerina utilities for the Care Loop HL7 AI Competition services
(`care-loop-analysis-service`, `care-loop-collector-service`, `care-loop-ai-service`):
dashboard event notification, FHIR connector/id helpers, and HTTP retry.

Consumed as a local-repository dependency (`bal push --repository=local`), not
published to Ballerina Central.
