# care_loop_common

Shared Ballerina utilities for the Care Loop HL7 AI Competition services (`care-loop-analysis-service`, `care-loop-collector-service`, `care-loop-ai-service`).

## Provides

- Dashboard event notification
- FHIR connector and id helpers
- HTTP retry

## Consumption

Used as a local-repository dependency (`bal push --repository=local`), not published to Ballerina Central.
